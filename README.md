# Bitácora del Arquero

App de una sola página para avanzar por las 4 fases de mi plan de arquero de futsal (oct 2026 a dic 2027).

- Sugiere qué hacer cada día: juegos en mis días de juego y gimnasio en el resto, sin pierna pesada el día antes de jugar.
- Cuota semanal por fase, racha y criterios para pasar de fase.
- Calendario tipo GitHub con lo hecho, lo planeado y lo sugerido.
- Registro de dolor (muñeca, ingle, rodilla, espalda) con una prueba y 4 niveles.
- Tests cada 6 a 8 semanas, partidos y pendientes.

Es un solo `index.html` sin dependencias (solo Google Fonts). Abierta como artifact de Claude guarda en la nube; abierta desde GitHub Pages o el archivo, guarda en el navegador (`localStorage`).

Los pesos de cada serie se anotan en [fierros](https://github.com/panchososososo/fierros).
